# Open Graph Images for Piano Triads

This directory contains social media sharing images for Piano Triads. All images should be optimized for social media sharing.

## Image Specifications

### Required Dimensions
- **Primary Size**: 1200x630 pixels (1.91:1 ratio) - Facebook/LinkedIn optimized
- **Twitter Alternative**: 1200x675 pixels (16:9 ratio) - Twitter optimized
- **Format**: JPG (preferred) or PNG
- **File Size**: Keep under 1MB for optimal loading
- **Color Space**: sRGB

## Design Guidelines

### Brand Colors
- Primary: #3480f1 (blue)
- Gradients: Use existing CSS gradients from the app
- Background: Clean, professional backgrounds

### Typography
- Use modern, readable fonts
- Maintain hierarchy: main title, subtitle, feature highlights
- Ensure text is readable at small sizes (Facebook preview)

### Layout
- Keep important text and visuals in the center 1200x630 safe area
- Consider how the image will look in various social preview sizes
- Leave breathing room around text and key elements

### Accessibility
- Ensure good contrast for text overlays
- Use alt text appropriately (already implemented in meta tags)
- Consider how images appear for users with different visual needs

## Testing
After creating images, test them using:
- Facebook Sharing Debugger: https://developers.facebook.com/tools/debug/
- Twitter Card Validator: https://cards-dev.twitter.com/validator
- LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/

## File Naming Convention
- Use lowercase with hyphens
- Match the canonical URL structure
- Keep filenames descriptive and SEO-friendly
